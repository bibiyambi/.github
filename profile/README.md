## 우리는 이런 팀입니다

비비얌비는 “이런 게 있으면 좋겠다”는 생각을 실제로 만들어보는 팀입니다.
통학과 출근을 준비하는 일상부터 좋아하는 음악을 발견하는 순간까지,
사람들이 불편을 느끼거나 즐거움을 찾는 지점에서 프로젝트를 시작합니다.

기획과 개발, 디자인과 마케팅을 연결하며 아이디어를 구체화합니다.
현장에서 사용자를 이해하고, 작은 프로토타입으로 가능성을 확인하며,
피드백을 다음 시도의 재료로 삼습니다.

## 우리가 만들고 탐색하는 것

### ⏰ 앗차! — 일정이 알림이 되도록

출근과 통학을 위해 여러 개의 알람을 직접 설정해야 하는 번거로움에서 출발한 일정 기반 알림 서비스입니다.

- 캘린더와 시간표를 가져와 일정에 맞는 알림을 만드는 경험을 기획합니다.
- 준비 시간과 이동 시간을 고려해 하루의 시작을 돕는 것을 목표로 합니다.
- 교통 정보에 따른 알림 조정과 캐릭터를 활용한 안내를 확장 방향으로 검토합니다.

### 🎧 인디스탑 · IndieStop — 좋아하는 음악과 더 가까이

인디 아티스트와 팬, 공연장을 연결하는 음악 정보·기록 채널을 기획합니다.
공연 일정과 아티스트 정보를 찾기 쉽게 정리하고, 현장에서 발견한 이야기를 콘텐츠로 담는 것이 출발점입니다.

- 공연 일정, 아티스트 소개, 인디씬 소식, 현장 콘텐츠를 네 가지 축으로 삼습니다.
- Instagram을 기반으로 팬과 아티스트가 만나는 접점을 만들어갑니다.
- 취향과 자율성, 현장성을 존중하는 팬 커뮤니티로의 확장을 탐색합니다.

### 🚘 차량용 앱 — 새로운 공간에서의 플레이

현대자동차그룹 차량용 앱 개발 공모전을 계기로 차량 환경을 위한 게임 경험을 탐색합니다.
‘별빛 베이커리’ 배경 시안을 비롯해 게임 화면과 프로토타입, 소개 콘텐츠를 준비하며
아이디어를 직접 보고 체험할 수 있는 형태로 구체화합니다.

### 🍔 브랜드 경험 — 제품을 넘어 참여로

프랭크버거 대학생 공모전에서는 사용자 조사와 페르소나를 바탕으로 브랜딩 전략을 구상했습니다.
버거 커스터마이징, 앱 경험, 팝업스토어와 콘텐츠 등 브랜드를 경험하는 여러 접점을 함께 살펴봅니다.

> 프로젝트 소개에는 기획 및 탐색 중인 내용이 포함되어 있습니다. 구현 범위와 공개 여부는 각 프로젝트의 문서를 기준으로 안내합니다.

## 우리가 일하는 방식

| 원칙 | 실천 |
| :--- | :--- |
| **사용자가 있는 곳에서 시작합니다** | 공연 현장과 기존 서비스, 사용자의 생활 흐름을 살펴봅니다. |

| **기록을 다음 실행으로 연결합니다** | 회의와 피드백을 문서로 남기고 역할과 다음 할 일을 정합니다. |
